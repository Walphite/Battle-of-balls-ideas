# 集锦素材放哪里

## 文件夹
- `input/clips/` ：放视频素材
- `input/music/` ：放配乐，**只放 1 个文件**
- `work/` ：程序自己用的缓存，不用管
- `output/` ：成片和预览会出现在这里

## 文件命名
格式：`年份_序号_一句话.mp4`，例如 `2021_03_团战翻盘.mp4`

- 年份必须是文件名开头的 4 位数字
- 没有年份的文件会被排在最后
- 序号用两位数字（01、02……），同一年内按序号排序

## 注意
- 请**复制**进去，不要移动，保留原文件
- 建议每段 10–30 秒，总共 20–40 段；少一点也能做，一段素材可以切出多个镜头
- 横屏、竖屏、不同分辨率和帧率都可以混放

## 放好之后
对我说「检查素材」，我会列出每个文件的年份、分辨率、帧率、时长、有没有声音，并标出命名不规范的文件。
