## 一、音频（样 G：`fxlab/docs/audio/audio_fix_before.wav` / `audio_fix_after.wav`，70–110 s）
- **原曲本身没有在 77–102 s 变小**（RMS 约 −3.6 dBFS、LUFS-S 约 −5.5，反而是全曲最响）。
- **根因 = 混音里的 loudnorm 回退为动态模式**：原曲积分响度 −7.3 LUFS、真峰值 +2.46 dBTP；要用 `I=−10.5,TP=−3` 做线性归一需要的增益会使峰值超过 −3 dBTP，所以 `linear=true` 不成立，ffmpeg 静默回退到 `normalization_type: dynamic`（已实测），持续高响度的 77.5–101 s 被其限幅器压到 −42 dB（比裁切后配乐低 ≈36 dB）；101 s 后恢复。
- 其他排查：BGA 音轨未混入（`-an`）；无压缩器/压低；裁切窗口无增益包络（整首 + 淡入淡出）；无立体声相位问题（mono 与 stereo 响度一致）。
- 修复：`volume −3.4 dB`（静态）+ `alimiter limit=0.72（−2.9 dBFS）lookahead 7ms release 150ms`（只防真峰值）；整首连续 `work/audio/mix.wav`（0–278.8 s）一次封装；AAC 用 `-aac_pns 0 -aac_is 0`（默认参数下 AAC 噪声替代/强度立体声会使真峰值冲到 +3.2 dBTP）。结果：−10.8 LUFS / −2.1 dBTP；混音相对裁切后配乐每 3 s 响度差中位 −3.40 LU、最大偏差 0.16 LU（≤0.5）；逐秒 RMS 无「连续 >3 s 低于 −25 dB」（仅 3–4 s 淡入处），231–233 s 的低谷（−25/−28 dB）原曲同位置就有。对照表 `audio/loudness_table.md`。
- preview_A 音轨时长 99.200 s = 画面时长（无缩短）；以后 A/B/C 都从同一个 mix.wav 切片封装，整片用 mix.m4a 一次封装（render_full.py 已改）。**已有的 preview_*.mp4 仍是旧音频，需重新封装/推送（视频不用重渲）。**
