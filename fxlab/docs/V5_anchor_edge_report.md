旧拍网格取自粗起音（STFT 窗起点约定），**相对真实起音系统性偏早 60.7 ms**（精细起音检测 hop 2.9ms，用合成爆破校准 −6.6ms 后；与时域攻击点中位差 +6ms 互证）。已把网格整体校正 +60.7 ms：全部镜头切点平移 +46…+78 ms（中位 +61），片段顺序、拍数不变，变速最大变化 0.0097。旧版 sample_D 里「画面早于网格 31–67 ms」与此一致。
BGA 事件到最近镜头边界：29.77→+50 ms、47.91→+15 ms、5.11→+912、44.57→+338、144.31→+139、187.21→+495、233.14→+147（命中 ≤40ms：1/7；其余只在事件时刻加 ≤4 帧重音）。

## 2. 边缘（fade_width=80、spill_width=120、spill_strength=0.38，960 宽度下像素）
窗口内容在边缘内 ≤80px（按余量等比缩小，左侧按钮/右上小地图处缩到 48px，顶边至少 12px 吃掉残留盾点条）线性+平滑曲线各半渐变到黑；窗口外 0–120px 叠加窗口边缘 ~40px 内平均色的模糊光晕（边缘处 38%，线性衰减到 0；色相取自画面）；满屏时渐变与光晕随余量缩为 0。1px 白线、外侧暗晕、内侧暗角、alpha 羽化全部删除。
5 个时刻（红 shot20 / 深蓝 shot23 / 亮白 shot80 / 暗紫蓝 shot22 / 暗红 shot108；关闭 BGA 字符叠加后实测），剖面 = 沿边缘取窗口中段 60% 平均，边缘内 80px → 外 120px：
- **窗口边缘外侧（光晕区）**：每 10px 最大变化 ≤ 5.1% 窗均亮，反弹 ≤ 1.6%（单调下降 ✓）。
- 含窗内 80px 的完整剖面：右、下边 ≤12.4%/≤17.7%；**左、上边 20–82%**，原因是窗内的触控按钮与顶部 HUD 本身的亮度起伏（对照：关闭渐变的参考渲染同区间数值相同：左 20.6–82.2%、上 28.1–59.0%），不是边缘造成的；左侧为保护按钮把渐变缩到 48px（下限）。
- 字符：墨水层 ≥ 原始（只提亮不压暗）；窗外 50%、窗内 25%、窗中心 ≤8% 的增益是规格要求。
